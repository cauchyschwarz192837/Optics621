# Model, equations and scientific boundaries

## Research interpretation

The source is a literature-motivated, Pockels-tuned narrow-linewidth laser. A separate MZM imposes a code, and an LO tapped upstream of the MZM remains uncoded. A stationary target contributes one delayed field. A second laser contributes an independent field. Ideal balanced detection cancels signal–signal beating and leaves the LO cross terms. A finite-bandwidth receiver, noise, ADC and range estimator complete the model.

The core question is not whether binary codes have low electrical correlation. It is whether the **complete coherent optical-field waveforms** remain distinguishable after mixing, bandwidth restriction, phase noise and propagation, at comparable power cost.

The model connects at least four course units:

| Course connection | Implemented connection | Important distinction |
|---|---|---|
| Waves in materials / guided optics | Tidy3D anisotropic LN modes and effective index | Separate component model; does not simulate the laser cavity |
| Electro-optic / nonlinear polarization | Pockels perturbation of optical impermeability | Pockels polarization is χ(2); MZM cosine distortion is interference |
| Optical modulation / interference | Complex two-arm MZM and coherent heterodyne readout | Field sign is retained |
| Statistical optics | Wiener phase histories, temporal coherence, coherent scatterers | Intrinsic linewidth is not a complete technical-noise model |
| Detection / information limits | Link budget, noise PSD, bandwidth, Fisher information and global detection | Single-target precision differs from two-target resolution |

## Configuration conventions

Except for explicitly suffixed values such as `_db`, `_um`, `_pm_v`, and `_mhz`, model parameters are SI units. JSON uses `null` to disable interference (`isr_db`). Codes are reproducible 100-chip periodic ±1 sequences generated by seeds 621 and 622, with raised-cosine transitions of 100 ns. Random codes are not guaranteed low-correlation code families; both full-field auto- and cross-ambiguity must be examined.

The source waveform exists before the usable observation interval, with 8 µs of history by default. The source chirp is extrapolated linearly over that guard interval and the code is periodic. This assumes the experiment provides a usable ramp with adequate guard time; it does not model ramp turnarounds. Additional guard tuning range and dead time must be budgeted for hardware. Only one up-ramp is simulated; there is no Doppler or up/down-pair estimator.

## Analytical optical-to-electrical reduction

For A, the delayed field relative to the LO has phase

\[
\theta_A(t;\tau)=-2\pi S_A\tau t+\pi S_A\tau^2+\phi_e(t-\tau)-\phi_e(t)+\phi_n(t-\tau)-\phi_n(t)+\phi_0.
\]

Here `S_A = sweep_hz/duration_s * (1+slope_error)`, and

\[
\delta\nu(t)=A_e\sin(\omega_e t),\qquad \phi_e(t)=-2\pi A_e\cos(\omega_e t)/\omega_e.
\]

A constant optical propagation phase is absorbed in the unknown phase. The optical carrier and 500 MHz optical sweep are never sampled as an optical waveform at the ADC rate. Only the analytically reduced beat is sampled.

For B,

\[
\theta_B(t)=2\pi\Delta\nu_0 t+\pi[S_B(t-\tau_B)^2-S_A t^2]-\phi_e(t)+\phi_{n,B}(t-\tau_B)-\phi_{n,A}(t)+\phi_{0,B}.
\]

B has a linear chirp; A's deterministic chirp error enters through its LO. B's code timing and initial optical phase are independently randomized each trial. B retains its own code in both uncoded-A and coded-A experiments, providing the same foreign waveform distribution.

Wiener phase increments have variance `2π linewidth Δt`. The implementation builds the **union of all requested time points** and samples increments over that exact ordered set. This preserves A/LO correlations at fractional delays without rounding or linear interpolation. B uses an independent history. The initial phase of each laser is a nuisance parameter.

## MZM voltage-to-field convention

Differential arm voltage V gives `phi1 - phi2 = π V/Vπ`. The model is

\[
m(V)=\sqrt{\eta_M}\,\frac{\sqrt{1+\epsilon}\,e^{i d/2}+\sqrt{1-\epsilon}\,e^{-i d/2}}{2}e^{i\alpha d/2},\quad d=\pi V/V_\pi.
\]

`arm_imbalance` is a fractional arm-power imbalance; `residual_chirp` controls common phase. With both zero, this reduces to `sqrt(eta_M) cos(πV/(2Vπ))`. Negative field transmission is preserved. Intensity-only measurements cannot fully identify this complex transfer when residual phase chirp is allowed.

The waveform is `V = Vbias + Vdrive c(t) cos(2πfc t)`. Its launched-power normalization is evaluated over the emitted usable ramp, not independently renormalized at every candidate delay. Thus delays retain the actual observation-window differences. Periodicity makes the power normalization independent of asynchronous code offset for a full code period under baseline settings.

The small-signal estimator linearizes the complex transfer around the bias; the simulated coded transmitter remains the full nonlinear model. This tests model mismatch rather than comparing two unrelated transmitters.

## Link and power budgets

For a beam smaller than a normal Lambertian surface:

\[
\bar P_r=\bar P_t\rho\,\frac{\pi(D/2)^2}{\pi R^2}\,\eta,\quad \bar P_c=\xi\bar P_r.
\]

This is a simplified collection model, with mean coherent-mode/polarization coupling ξ. It omits pointing jitter, target BRDF detail, weather and atmospheric turbulence. No eye-safety compliance is inferred from a wavelength or launched power.

With unit-average-power field `u=m/sqrt(mean(|m|²))`,

\[
i_A(t)=2\mathcal R\sqrt{P_{LO}\bar P_c}\operatorname{Re}\{u(t-\tau)e^{i\theta_A(t)}\}.
\]

The model adds B's current with coherent power `Pc * 10^(ISR/10)`. Hence field amplitude scales as `10^(ISR/20)`. ISR is referenced to the nominal target even in target-absent trials, so H0 does not inadvertently remove B.

`equal_launch` fixes average launched power, reporting the necessary incident source and peak launch powers. `equal_source` fixes the incident source power; uncoded A bypasses the MZM. This deliberately captures the engineering advantage of omitting a lossy component. LO power is independently fixed: the model does not solve a shared source-splitter optimization.

By default the ISR grid is relative to each method's desired power. For fixed absolute foreign illumination, set `foreign_reference_coherent_w` to the same positive value in all compared configs: `PB = reference * 10^(isr_db/10)`. The exported `actual_isr_db` then differs between methods. The power campaign supplies both interpretations.

For foreign shot noise, the collected foreign power is estimated as `PB/coupling`, using the same mean coupling as A. Revise this if the interferer has a different spatial/polarization coupling. Shot noise uses mean power; sub-ramp modulation of shot-noise variance is neglected under LO-dominated operation.

## Receiver and whitening

One-sided input PSD is

\[
S_i=2q\mathcal R(P_{LO}+P_{A,r}+P_{B,r}+P_{bg})+i_{elec}^2.
\]

At the internal rate, independent real Gaussian samples have variance `Si fsim/2`. Noise and signal pass through the same causal eighth-order Butterworth filter before decimation. The implementation uses a bilinear digital filter at the internal rate as an analogue surrogate, which converges toward the desired analogue response with oversampling. It does not use an acausal zero-phase filter in the physical receiver.

The ADC rate is 50 MS/s; receiver cutoff is 20 MHz. The analog surrogate is not a brick-wall filter, and residual noise above ADC Nyquist aliases. The stationary whitening model explicitly sums the filtered PSD over decimation aliases. Analysis then uses 0.05–19 MHz (`full`) or 4.5–10 MHz (`sideband`). The upper sideband selection stays above the nominal 10–100 m carrier beats, but sharp finite-window spectral leakage is still possible. A different range interval needs a new sideband allocation.

PSD whitening approximates the finite-record noise covariance as circulant. It is not exact finite-window generalized least squares. Empirical H0 calibration and held-out H0 validation protect the stated false-alarm experiment against blindly assuming a chi-square statistic. Additional receiver dynamics and coloured electronics noise would require a new PSD model.

`clipping_a` clips the filtered ADC input. This is an ADC dynamic-range sensitivity test, not a photodiode/TIA saturation model. Out-of-band photocurrent saturation and time-varying shot noise are not included. The frequency guard rejects obvious numerical alias cases but is not a proof of negligible spectral tails; convergence is mandatory for high drive, fast transitions or a stronger foreign laser.

## Range search and Fisher information

At each trial range generate the real and imaginary quadratures of the delayed calibrated field, then filter, decimate and whiten them exactly as the measurement. QR produces an orthonormal two-dimensional basis `Q_R`. The score is `||Q_R^T y||²`, fitting unknown phase and amplitude. The maximum over the entire declared range interval is refined continuously with a bounded scalar optimizer.

The uncoded demo reports an FFT initializer, but the final uncoded comparator uses the same global calibrated quadrature search. In a linear chirp this is a continuously refined sinusoidal spectral search. This ensures the uncoded method receives the same chirp calibration rather than being penalized with FFT-bin quantization. The default 0.075 m grid is about one quarter of the nominal resolution. Refine the global grid to test ambiguous cases and parameter changes; local refinement alone cannot recover a globally missed peak.

The template derivative with respect to range is projected away from amplitude/phase nuisance directions. The approximate local range bound is

\[
\sigma_R\ge\sqrt{(S_i f_{ADC}/2)/\|P_{\perp} \partial s/\partial R\|^2}.
\]

This is a local stationary-noise approximation, not a bound including unknown calibration, phase noise, speckle or interference. Bias can dominate and a wrong global peak can invalidate local precision intuition. A small-signal mismatched-template bound is only a diagnostic of that assumed model.

## Independent synthetic calibration

`calibrate()` creates a separate voltage-to-complex-field dataset, with its own random seed, then fits Vπ, insertion loss, arm imbalance and residual phase chirp. The bias has independent readback error. The known commanded voltage sweep and an approximate prior bracket around Vπ are assumed. This is a virtual coherent calibration experiment, not inference from the unknown target return.

The delay-MZI calibration receives noisy **unwrapped phase**. A linear fit estimates slope and the declared sinusoidal chirp-error basis with a free phase constant. The delay used by the estimator can differ from the true delay, leaving a systematic range error. This deliberately excludes photodetector sampling, phase extraction, phase-unwrapping failures, unmodeled chirp components and a full predistortion loop. The declared basis and calibrated waveform are shared fairly by the three primary methods.

If hardware calibration supplies measured values, add a loader for those values or construct the estimator configuration explicitly. The simulator never treats an unmeasured device as calibrated merely because its exact parameters are known internally.

## Speckle

For `scatterer_count>1`, equal-power scatterers have independent uniformly random phases and Gaussian depth offsets around the nominal range. Fields add coherently; expected total power before interference is the link budget. Fades and apparent-range shifts arise naturally. This is a bounded rough-target model with no spatial scanning or angular correlation. Error is referenced to the nominal surface centre, which need not equal the instantaneous coherent apparent surface. With one scatterer, the random phase is a nuisance phase without an amplitude fade.

## Tidy3D component boundaries

The component script models a rectangular lithium-niobate ridge/slab in silica. Laboratory propagation is y; crystal Z is laboratory x; crystal X is laboratory z. Optical tensor entries are `diag(ne²,no²,no²)` in laboratory coordinates. With an assumed uniform RF field along crystal Z,

\[
\Delta(\epsilon_r^{-1})_{xx}=r_{33}E_3,\quad
\Delta(\epsilon_r^{-1})_{yy}=\Delta(\epsilon_r^{-1})_{zz}=r_{13}E_3.
\]

The script applies the perturbation to the LN material, solves guided modes at −V, 0 and +V, tracks mode identity across voltage by field overlap, and estimates `dn_eff/dV_arm`. For differential drive ±V/2,

\[
V_\pi=\lambda/[2L|dn_{eff}/dV_{arm}|].
\]

Mesh, domain-size and voltage-step convergence are tested. The code checks x-polarized mode selection, but a person must inspect the field plots and convergence before treating the selected mode as the intended guided mode. Constants and dimensions in the two supplied designs are assumptions; neither design reproduces the official tutorial's full RF stack. The uniform RF field is the minimum viable EO approximation from the prior project plan. A stronger study would replace it with a quasi-static electrode solution.

No group index, metal absorption, propagation scattering, electrodes, bends, splitter imbalance, packaging, RF impedance, velocity matching or fabrication tolerances are extracted by this simplified component solve. These cannot be inferred from a lossless eigenmode. Insertion loss stays a separate system parameter. The laser source's 28 MHz/V tuning assumption is independent of the MZM's computed Vπ.
